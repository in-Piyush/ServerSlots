# ServerSlots
https://modrinth.com/plugin/serverslots
A lightweight Paper plugin that lets you dynamically change your server's max player slots without restarting the server.

Perfect for:

* Maintenance mode
* Events & tournaments
* Reserved staff slots
* Temporary player limits
* Performance control during high load

### Features

* Change max slots instantly
* No restart required
* Lightweight & optimized
* Paper 1.21+ support
* Simple command system

### Command

`/serverslots <amount>`

### Example

```text
/serverslots 50
```

Changes the server max player count to 50 instantly.
